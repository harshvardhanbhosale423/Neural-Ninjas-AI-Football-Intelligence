# Demo recording plan (about 110 seconds, to be recorded in English)

**0–10 sec — Introduce.** “Neural Ninjas turns football match events into readable, evidence-backed match intelligence. These examples are synthetic.”

**10–25 sec — Personalize and select.** Choose English or Marathi and Fan or Analyst view. Select Harbor City vs Pinebridge; point out the score and synthetic-data label.

**25–40 sec — Show evidence.** Read the shot and pass metrics, then filter the event timeline to goals or to the second half. Show the 89th-minute winner.

**40–55 sec — Generate a recap.** Switch Fan / Analyst views to show different summary lengths. Explain that this build uses transparent local rules, not a live model.

**55–70 sec — Inspect insights.** Point to the supporting counts and caveat that shot volume is not chance quality.

**70–85 sec — Ask your match.** Ask “Why did the winner win?” Show recorded facts, interpretation and limitation.

**85–100 sec — Player view.** Select a player and explain the transparent, limited event indicator.

**100–110 sec — Export and close.** Download the selected match report. Close by saying the demo is local, synthetic and designed to make football event data more understandable.

## Recording checklist

- Use a readable browser size and close unrelated tabs.
- Start the local server and verify the page before recording.
- Keep the cursor away from text being read.
- Show the synthetic-data label, Marathi option and Q&A limitation.
- Test the question and report download before recording.
- Keep the published video under two minutes. The official rules require English materials or an English translation of the video and other materials.
