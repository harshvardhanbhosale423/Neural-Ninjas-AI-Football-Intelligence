# Project pitch

Football produces a lot of numbers, but numbers alone do not tell everyone what happened or what those numbers can actually prove. Neural Ninjas is a local-first football intelligence prototype that turns synthetic match events into clear recaps, player summaries and tactical observations. Every observation points back to recorded events or stated synthetic aggregates, and every answer includes limits on what sparse data cannot tell us.

Fans, students and coaches can switch between three fictional match scenarios, follow a filtered timeline, ask questions in plain language, and download a report for the selected match. English and Marathi language options and Fan / Analyst views let audiences choose how they read the same evidence. Its current intelligence engine uses explainable local rules; it works without credentials or a network service and does not pretend to use a live language model. The project demonstrates a practical bridge from event data to accessible narrative while making uncertainty visible. This prototype is educational, synthetic and not a replacement for professional analysis or player-tracking systems.

**Technology disclosure:** The app uses HTML, CSS and JavaScript, with a Node.js server and an optional Microsoft Foundry Models v1 chat-completions integration.
